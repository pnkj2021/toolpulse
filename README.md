# YBS — Your Browser Suite

Everything you need. Right in your browser.

YBS is a growing collection of fast, privacy-first browser tools for developers, students, creators, and professionals. Tools run locally in the browser where stated, with no account or installation required.

## Development

```sh
npm install
npm run dev
```

Use `npm run build` for a production build, `npm run check` for Astro and TypeScript validation, and `npm test` for the test suite.

Set `SITE_URL` to the deployed origin. The default is `https://ybs.tools`.
